# Unit 3: Long Bone Anatomy

A visual identification quiz covering the 12 unique structures labeled in the supplied long-bone reference. Repeated epiphyseal line, articular cartilage, and epiphysis labels are combined into one question per structure.

`long-bone.png` is an AI-assisted unlabeled adaptation of the user-supplied diagram. Targets are calibrated to the adapted image using a 1256 × 1792 reference grid. The nutrient foramen target marks the point where the nutrient vessel enters the shaft; regional epiphysis and diaphysis questions use brackets instead of tissue dots.

Open `index.html` through a static HTTP server. The quiz has no external runtime dependencies; it uses the site's shared styles.

Run the quiz checks with `node --test long-bone-quiz/core.test.mjs` from the repository root.
